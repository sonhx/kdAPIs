sequenceDiagram autonumber actor User as Người dùng (Admin) participant UI as Giao diện qa-ims participant Controller as SurveyCommentsController participant Worker as RunProcessingService (Async) participant Gemini as Google Gemini API (gemini-3.8-flash) participant Repo as RunRepository User->>UI: Kéo thả sample_fake_comments.csv & Bấm bắt đầu UI->>Controller: POST /runs (kèm file, surveyId, X-Session-Id) Controller->>Controller: Kiểm tra hợp lệ phiên đăng nhập Controller->>Repo: Khởi tạo Run (runId, PENDING) Controller->>Worker: Gửi tác vụ chạy nền (submitRun) Controller-->>UI: HTTP 202 Accepted (runId, status=PENDING) loop Polling mỗi 2 giây UI->>Controller: GET /runs/{runId} Controller->>Repo: Lấy tiến độ hiện tại Controller-->>UI: Trả về trạng thái (status, classified/total) UI->>UI: Cập nhật Progress Bar & Stepper end Note over Worker: Ingest -> Clean -> Redact PII Worker->>Worker: Che giấu thông tin cá nhân (MSSV, Email, Phone, Tên) loop Phân loại từng ý kiến đã che PII Worker->>Gemini: Prompt (Ngữ cảnh câu hỏi + Codebook 12 chủ đề) Gemini-->>Worker: JSON (themes, sentiment, confidence, suggestions) Worker->>Worker: Schema Validation & Phân loại Review Queue Worker->>Repo: Cập nhật tiến độ (classifiedComments++) end Worker->>Repo: Lưu toàn bộ kết quả & Đổi trạng thái -> DONE UI->>Controller: GET /runs/{runId} -> Nhận status = DONE UI->>Controller: GET /runs/{runId}/results & GET /runs/{runId}/cost Controller-->>UI: Dữ liệu phân loại chi tiết & Thống kê Token / Chi phí UI->>User: Hiển thị Bảng kết quả, KPI Cards & Mở nút Tải báo cáo opt Tải Báo cáo User->>UI: Bấm "Tải Báo cáo Excel (5 Sheets)" UI->>Controller: GET /runs/{runId}/report?format=xlsx Controller-->>User: Tải trực tiếp file survey_comments_report.xlsx end
